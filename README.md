# 姑姑生日快乐 · 微信可打开的 H5 祝福页

**线上地址：https://brucebility.github.io/gugu-birthday/**（GitHub Pages，HTTPS）

单文件、零依赖：没有外部图片、字体、音频文件（音效用 Web Audio 现场合成），
把 `index.html` 传到哪里都能直接打开。

| 文件 | 说明 |
|---|---|
| `index.html` | 页面本体（23 KB） |
| `aunt.jpg` | 肖像图（820×1764，324 KB），点蛋糕后全屏弹出 |
| `preview.png` | 预览截图（照片弹出状态） |

## 一、改内容

打开 `index.html`，只改 `<head>` 里那段 `window.CONFIG`：

```js
window.CONFIG = {
  title: '姑姑，生日快乐！',        // 大标题
  subtitle: '今天您说什么都对 · 想吃几块蛋糕就吃几块',  // 副标题
  signature: '—— 您最懂事的侄子',   // 落款
  portrait: 'aunt.jpg',            // 肖像图，放同目录；留空则不弹照片
  portraitCaption: '本人认证 · 永远十八岁',  // 照片下方小字
  wishes: [                        // 祝福卡片，想加几条加几条
    { emoji: '🎂', text: '……' }
  ]
};
```

- **换肖像**：把图片放到和 `index.html` 同一目录，改 `portrait` 指向它即可。
- 落款写你自己的名字（侄子/外甥按实际情况改）。

## 二、本地看效果

- 双击 `index.html` 直接用浏览器打开；
- 或在目录里执行 `python -m http.server 8000`，访问 `http://localhost:8000`。

## 三、发到微信（关键一步）

微信内置浏览器只认 **https 公网链接**，本机文件是打不开的。三种方式：

1. **GitHub Pages（推荐，免费）**
   新建仓库 → 上传 `index.html` → 仓库 Settings → Pages → Source 选 `main` / 根目录 → 保存。
   一两分钟后拿到 `https://<用户名>.github.io/<仓库名>/`，把链接发给姑姑。
2. **Vercel / Netlify**：把整个文件夹拖进去，直接给 https 链接。
3. **已有服务器 / 对象存储**：丢上去，确保是 https。

## 四、交互清单

| 操作 | 效果 |
|---|---|
| 点蛋糕 | 蜡烛熄灭 + 彩纸炸开 + 上行音效，0.5 秒后**照片全屏弹出** |
| 点任意处（或 Esc） | 关闭照片，提示语变成「再看一眼照片」 |
| 「再看一眼照片」按钮 | 重新打开照片 |
| 再点蛋糕 | 重新点亮蜡烛，可以再许一次 |
| 点气球 | 气球炸开 + 掉彩纸 |
| 点祝福卡片 | 卡片抖一下 + 清脆音效 |
| 右上角按钮 | 音效开 / 关 |

## 五、已验证 / 未验证

**已验证**（本机 Edge 无头渲染实测）：

- 492px 与 iframe 内 375px 两档宽度下排版正常、无横向溢出
- 点蛋糕后：蜡烛熄灭、彩纸绘制、照片层弹出、点空白处关闭、「再看一眼」按钮出现
- 两段内联脚本语法检查通过；全文 0 个外部 URL（断网也能用）

**未验证**（没有真机 / 没有微信客户端）：

- 微信 iOS / Android 真机上的最终观感与音效（iOS 需要先点一下页面才出声，这是浏览器策略，不是 bug）
- 老款安卓 X5 内核下的表现：已把 `aspect-ratio`、`gap`、`clamp` 换成兼容写法，但没在低版本内核上实测
- 照片弹出的淡入过渡在真机上的实际手感（无头截图不推进 CSS 过渡，无法逐帧验证）
